- Architected a fault-tolerant, event-driven enforcement pipeline: HMAC-validated GitHub webhook ingress → Inngest async orchestration → concurrent LLM-based policy evaluation against a cloned repo checkout → real-time GitHub check-run updates, with retries and idempotency at every stage.

- Built an <b>online and offline eval infrastructure</b> — online evals score policy violations in real-time on every PR check; offline evals run curated LLM tool-call trace datasets through Opik & Databricks with MLflow tracking, enabling regression testing and data-driven model selection.
